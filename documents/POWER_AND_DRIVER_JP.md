# LightBox — 電力・低電力・LEDドライバ 設計メモ

[English](POWER_AND_DRIVER.md) · **日本語** · [← README](../README_JP.md)

バッテリ/低電力機能・常夜灯の種類・本体LEDドライバ選定に関する設計記録。
項目別リファレンスは [CONFIG_REFERENCE_JP.md](CONFIG_REFERENCE_JP.md)、コア設計判断は
[DESIGN_JP.md](DESIGN_JP.md) を参照。**★実験的**はコンパイル対応だが**実機未検証**。

---

## 1. 機能↔ピン割当（config 主導にした理由）

動機は SOP8(J4M6) の PCB 簡素化。データシートのピン配置は電源が pin2/4(VSS/VDD)、GPIO が pin5–8 に集中:

- ロータリエンコーダ＋押しSW を **PC1/PC2/PC4**(pin5–7) に集約 → 5端子のエンコーダ部品を片側にまとめられ配線が素直。
- 出力を **PA1/PA2**(pin1/3, 電源近傍) に置く → LED/出力部を VDD/VSS 側の別ゾーンにまとめられる。

CH32V003 は PWM(タイマ channel/remap) と ADC の可否がピンで縛られるため、`source/pins.h` が
各 SOP8 ピンの能力をモデル化し、単一ピンマクロから GPIO/ADC/タイマ情報を導出、能力違反とピン衝突を
コンパイル時に弾く。表と規則は [CONFIG_REFERENCE_JP.md](CONFIG_REFERENCE_JP.md) の「機能↔ピン割当」。
`PWM_PIN=PA1`(TIM1_CH2)＋常夜灯を PA2＋エンコーダを PC1/PC2/PC4、という配置も表現可能。

## 2. 自動消灯タイマ（`PWM_ON_TIME_S`）

点灯から N 秒で本体をソフト消灯（`0`=無効）。エンコーダ/押しSW 操作でリセット(延長)。平均点灯時間を
下げてバッテリに効き、常時電源でも「切り忘れ防止」の付加価値。1秒刻みで数えるので SysTick(~89s)ラップ非依存。

## 3. 常夜灯の種類（`NIGHTLIGHT_TYPE`）

- **① WS2812/SK6812**（`NL_TYPE_WS2812`）— カラー・演出優先(従来)。deep sleep 非対象
  (CPUタイミングがシビア／コイン電池では電圧不足)。
- **② 単色LED**（`NL_TYPE_SINGLE`）— 専用ピンを `NL_PERIOD_S` 秒おきに `NL_ON_MS` 点灯。
  `NL_USE_PWM=0`=GPIO 単純ON/OFF(最小CPU/電力) / `=1`=ソフトPWM明滅(演出)。
  **②＋`NL_USE_PWM=0` のときだけ**深い低電力の対象。

常夜灯電流は**直列抵抗**で設定(ドライバIC不使用)。5V で白色LEDを ~1kΩ なら ≈1.8mA、常夜灯に十分かつ
頭上余裕で電流安定。

## 4. 深い低電力モード（Standby + AWU）★実験的

バッテリモード(`LOW_POWER_MODE=1`, `source/lowpower.h`)。設計判断:

- **低電力常夜灯構成のみ対象**: ②単色LED＋`NL_USE_PWM=0`＋`NL_PERIOD_S≤30`＋`WDT_ENABLE=0` を要求
  (`_Static_assert`)。WS2812/PWM演出は従来の常時稼働アーキ(演出優先)。
- **スリープ構造**: 点灯 `NL_ON_MS` は **Sleep**(GPIO保持) で行い、残り時間は **Standby**(最深・µA級)。
  両区間とも **AWU(LSI≈128kHz, クロック非依存)** で計時。押しSW を **EXTI** 起水源にも設定。
  AWU 1サイクル上限 ≈30s → `NL_PERIOD_S≤30`。
- **起水モデル**: **押しSW** で通常ディマー動作に復帰し `LOWPWR_ACTIVE_WINDOW_S` 維持、その後 本体消灯なら
  スリープへ戻る。**ロータリエンコーダは意図的に Standby 起水源にしない**(2相 EXTI は複雑・プルアップが漏れる)。
- **リーク対策**: スリープ前にエンコーダ A/B を**アナログ入力化**しプルアップのリークを停止
  (~30–50kΩ プルアップに接点が閉だと ~100µA 流れ、Standby より大きい)。押しSW はプルアップ温存
  (常開=待機リークほぼ0、押下=Low で起水)。
- **再書込みセーフティ**: 起動時に押しSWを押していれば通常モードに留まりスリープしない(SWD 接続可)。
  これはリセット耐性も兼ねる: Standby 復帰が reset/resume どちらでも、`main` 再実行(または resume ループ)が
  ボタン状態から同じ判断に至る。
- **ウォッチドッグ**: `WDT_ENABLE=0` 必須 — IWDG は LSI 駆動で Standby 中も動き、AWU 前にリセットしうる。

**状態**: Standby/AWU/EXTI 経路はコンパイル対応だが**実機での確認が必須**(Standby 復帰・AWU 周期・実電流)。
`LOW_POWER_MODE=0`(既定)は従来ファームと byte 同一。

## 5. 電池寿命の見積り

前提(明示・★実機要確認): 緑LED を 1kΩ・3V で ≈**0.9mA** / Standby ≈10µA / アクティブ48MHz ≈8mA /
点灯中Sleep@48MHz ≈3mA / 起床overhead ≈5ms / CR2032 ≈220mAh。平均電流は **「点灯時間を MCU がどう過ごすか」**
が支配的で、LED ではない。

コイン電池(3V) 常夜灯、5秒おきに 100ms:

| 構成 | 平均電流 | CR2032 寿命(見積) |
|---|---|---|
| 深い低電力(実装形: 点灯中 48MHz Sleep) | ~90µA | **~3〜4ヶ月** |
| 深い低電力＋点灯中クロック低下(将来最適化) | ~45µA | ~6.5ヶ月 |
| 深い低電力なし(48MHz 常時) | ~8mA | ~1日 |

- **抵抗バイアス vs 明るさ/寿命**: 510Ω(~1.8mA)は明るいが寿命ほぼ半分。**1kΩ(~0.9mA)が最良バランス**。
  ~1–2kΩ を超えると寿命は MCU+Standby の下限に漸近するので、以降は点灯時間短縮/クロック低下で延ばす。
- **セル選択**: CR2032×2 直列は電圧(6V)は倍だが**容量は増えず**、6V は CH32V003 の 5.5V 上限超過
  (要降圧=LDOで余剰エネルギーを捨てる) → LED電流の安定には効くが mAh 寿命には効かない。寿命重視は
  **並列**(~440mAh) か大容量セル(CR2450 ~600mAh ≈約2年)。CR2032 のパルス/内部抵抗対策に 10–100µF。

GUI 設定エディタは単色LED常夜灯でこの CR2032 目安を 1kΩ 前提でライブ表示する。

## 6. 本体LEDドライバの選定

**確定条件:** 5V単一電源 ・ 白色系 本体LED ・ 常夜灯は抵抗で電流設定 ・ 本体PWMは **≤2kHz**
(CN5711 の CE ピンで調光するため)。

### CN5711 (Consonance) — 採用候補
リニア定電流ドライバ: Vin 2.8–6V、最大 **1.5A**、低ドロップ **0.37V@1.5A**、±5%、オンチップMOSFET＋センス、
電流は **ISET抵抗**(≤30kΩ)で設定、**温度レギュレーション(フォールドバック)**、SOP8。
**CE ピンへの PWM で調光(<2kHz)**。採用時は個別 MOSFET(FDS5680)ゲート駆動を置換
(LED陽極→5V、陰極→CN5711 LEDピン、CE←MCU の PWM)。

**最大の注意 — リニアである点:** `(Vin − Vf) × I` を IC 自身で熱にする。5V→白色LED(~3.2V)ではドロップ ~1.8V:

| 本体LED電流 | CN5711 損失 | SOP8(放熱パッド) |
|---|---|---|
| 100mA | ~0.18W | 余裕 |
| 300mA | ~0.54W | 良好(銅箔広め) |
| 500mA | ~0.9W | 際どい |
| **1A** | **~1.8W** | 過大→温度フォールドバック(自動減光) |

現行 MOSFET＋抵抗が「発熱ほぼ無し」だったのは `(Vin−Vf)` 損失が外部電流制限側にあった/LED電流が控えめ
だったため。リニアドライバは**その損失を小さな SOP8 に集中**させる。よって ~1A 白色/5V では CN5711 は
フォールドバックする。

### 代替
- **AMC7135** — より安いリニアCC、固定350mA(並列でN倍)、全体PWM。最安だが粒度固定・発熱大。
- **PT4115 / AL8860 / MT7202** — **降圧(buck)** CC、DIM ピン(PWM, >2kHz も可)。Vin≫Vf や電池で高効率、
  `(Vin−Vf)` を熱にしない。インダクタ＋ショットキーで BOM/面積増。

### 判断（本体LED電流別, 5V, 白色）
- **≤ ~300–400mA → CN5711 が最適**: 簡潔・低ドロップ・部品少・温度フォールドバック内蔵
  (MCU 側の温度保護も軽くできる)。
- **~1A → 降圧ドライバ(PT4115等)** か LED電流を下げる、または MOSFET＋CC のまま。

### ≤2kHz CE 調光の firmware 反映
本体 PWM を ≤2kHz に。例) `PWM_TOP=23999, PWM_PSC=0` → 48MHz/24000 = **2kHz**(24000段, ちらつき無し)。
あるいは MOSFET 高速PWM のままにして CC IC を足さない。
